# Week 04

## Project 1 — Movie Recommendation System

This project implements a **content-based Movie Recommendation System** using the TMDB 5000 movie dataset.

The system recommends movies similar to a selected movie by analyzing movie metadata such as:

- Movie overview
- Genres
- Keywords
- Cast
- Director

### Recommendation Approach

The project uses:

**TF-IDF**

TF-IDF converts movie metadata into numerical feature vectors.

**Cosine Similarity**

Cosine similarity is used to calculate the similarity between movies and identify movies with similar metadata.

### Main Steps

1. Load the TMDB datasets
2. Perform Exploratory Data Analysis
3. Handle missing values
4. Merge movie and credits datasets
5. Clean movie metadata
6. Extract genres and keywords
7. Extract top cast members
8. Extract director information
9. Create the combined `tags` feature
10. Apply TF-IDF
11. Calculate cosine similarity
12. Build the recommendation function
13. Perform qualitative evaluation
14. Save processed data and model files
15. Create a reusable Python recommendation script

### Dataset

The project uses:

- `tmdb_5000_movies.csv`
- `tmdb_5000_credits.csv`

### Sample Movie Queries

The recommendation system was tested using:

- Avatar
- Interstellar
- The Dark Knight Rises

The system successfully returned similar movies along with their similarity scores.

### Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Jupyter Notebook
